# 4Ever Wedding

Una demo interattiva, elegante e mobile-first per organizzare il matrimonio con meno stress.

## Avvio rapido sul Mac

1. Apri il Terminale.
2. Trascina questa cartella nella finestra del Terminale dopo aver scritto `cd ` (con uno spazio).
3. Premi Invio.
4. La prima volta, esegui `npm install`.
5. Avvia la demo con `npm run dev`.
6. Apri nel browser l'indirizzo che appare nel Terminale (normalmente `http://localhost:3000`).

Per fermare la demo, torna nel Terminale e premi `Control + C`.

## Cosa include

- Dashboard della coppia e countdown al 4 giugno 2027
- Checklist interattiva con filtri e nuove attività
- Budget, riepilogo e categorie di spesa
- Lista invitati con conferme modificabili
- Fornitori divisi per categoria
- Raccolta di ispirazioni salvabili
- Dati di esempio realistici
- Salvataggio automatico delle modifiche nel browser

La demo non richiede login, pagamenti o database online.
